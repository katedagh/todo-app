# To-Do List App

A simple to-do application built with HTML, CSS and JavaScript.
[Live Demo](https://katedagh.github.io/todo-app/)


## About the Project

This project was created as a practice project to improve my JavaScript skills and gain experience in building interactive web applications.
The application allows users to manage their daily tasks through a simple and intuitive interface.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Persist tasks after refreshing the page

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage

## What I Learned

- DOM manipulation
- Event listeners and event handling
- Working with arrays and objects
- Dynamically creating and updating HTML elements
- Working with Local Storage
- Managing application data and synchronizing it with the UI
